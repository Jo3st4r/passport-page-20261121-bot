An open passport spread for the **Republic of Veskar** — a small North Atlantic island republic that does not exist. One program, one image: a data page and a visas page that read as a single working document.

The data page shows holder Ingrid Marie Halvorsen of Kaldvik, passport VK 483 917, issued 02 FEB 2026, with a drawn portrait, bilingual Veskari/English fields, a signature, and a machine-readable zone whose check digits are computed to the ICAO 9303 TD3 layout. The visas page carries her 2026 travel history — an Ostara visitor visa, arrival in Port Meridian (Aurelia), entry to Ostara, a nine-day trip to Ternmark, and re-entry to Kaldvik — every stamp dated after the passport's issue and inside the visa's validity. The telling detail: holders must register with the Harbourmaster within 48 hours of landing, and a 40-krone landing fee stamp is paid. Veskar runs on its harbours and its fishing fleet.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

Writes `/output/entry.png` (1024x1024 PNG, deterministic — two runs produce identical bytes). Python 3.13, standard library + Pillow, no network.
